# 穿越者 0.3.0

在离线版分别设置空战、陆战地面载具和陆战历史固定翼的最高分房权重。

## 下载

- [下载穿越者 0.3.0 ZIP](https://github.com/2327569701-bot/wt-offline-time-traveler/releases/download/v0.3.0/time-traveler-v0.3.0.zip)

[查看发布说明](https://github.com/2327569701-bot/wt-offline-time-traveler/releases/tag/v0.3.0)

## 安装

1. 退出游戏。若装过旧版穿越者，先把旧模组移出 `Mod`。
2. 解压上面的 ZIP，把包内的 `Mod`、`backend`、`tools`、`work` 复制到 `WarThunderOffline.exe` 所在目录，按包内说明覆盖同名文件。
3. 启动游戏，在模组管理器中打开穿越者，调整并保存分房。

适用于与本项目同构建的 War Thunder Offline 2.59.0.92。若也要安装主菜单在线人数，先安装人数补丁。与 DTC201-125 合用时，需保留加载器的 `char` 资源和 `ztz99aDtc201` 支持。
